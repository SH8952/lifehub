## 1. 우리 동네 미세먼지 (대기질 API)

### Option A: OpenWeather Air Pollution API **(추천)**

| 항목 | 내용 |
|-----|------|
| **무료 티어** | ✅ 있음. 현재 날씨 API 키 하나로 사용 가능 |
| **일일 무료 호출** | 제품별 일일 무료 한도 있음 (pay-as-you-go) |
| **제공 데이터** | `aqi` (Air Quality Index), `components`: CO, NO, NO2, O3, SO2, PM2.5, PM10, NH3 |
| **한국 커버리지** | ✅ 전 세계 커버리지, 한국 도시 데이터 있음 |
| **인증** | API key (무료 계정으로 발급) |
| **애드센스 적합** | ✅ 무료 티어로 시작 가능, 상업 사용 가능 |
| **요금** | 무료 티어 → 과금제 (pay-as-you-go) |
| **API 예시** | `https://api.openweathermap.org/data/2.5/air_pollution?lat=37.5665&lon=126.978&appid={key}` |

**장점**: 무료 시작, 한국 데이터 존재, PM2.5/PM10 모두 제공, AQI 직접 제공
**단점**: 실시간 업데이트 주기는 제품별 상이

### Option B: WAQI (World Air Quality Index) API

| 항목 | 내용 |
|-----|------|
| **무료 티어** | ✅ 있음 (widget API는 무료, programmatic API는 제한적) |
| **제공 데이터** | AQI, 주요 오염물질, 예보 |
| **한국 커버리지** | ✅ 100+ 국가, 한국 주요 도시 |
| **상업 사용** | ⚠️ 영리 목적은 WAQI 팀과의 명시적 계약 필요 |
| **비상업 사용** | 출처 표기 시 가능 |
| **API 예시** | `https://api.waqi.info/feed/@lat,lon/?token={token}` |

**장점**: 전 세계 데이터, widget 위젯 제공
**단점**: ⚠️ 상업적 사용 시 별도 계약 필요, 애드센스 사이트에 쓰려면 commercial license 필요

### Option C: WeatherAPI.com Air Quality

| 항목 | 내용 |
|-----|------|
| **무료 티어** | ❌ 없음 (모든 기능이 유료) |
| **제공 데이터** | AQI, PM2.5, PM10, 오염지수 |
| **요금** | Starter $15/월부터 |

**장점**: 통합 날씨+대기질 API
**단점**: 무료 티어 없음

### 결론: **OpenWeather Air Pollution API 사용 권장**
- 무료 티어로 시작 가능
- 상업적 사용 제한 없음
- PM2.5, PM10 모두 제공
- 한국 데이터 커버리지 확인됨

## 2. 전국 실시간 자외선 지수 (UV Index API)

### Option A: OpenWeather One Call 3.0 / 4.0 **(추천)**

| 항목 | 내용 |
|-----|------|
| **무료 티어** | ✅ 있음. 일일 무료 호출 + pay-as-you-go |
| **자외선 데이터** | ✅ `uvi` 필드 (current, hourly, daily 모두 제공) |
| **한국 커버리지** | ✅ 전 세계 커버리지 |
| **API 예시** | `https://api.openweathermap.org/data/2.5/onecall?lat=37.5665&lon=126.978&appid={key}&exclude=minutely` |
| **제공 필드** | `current.uvi`, `hourly[].uvi`, `daily[].uvi` |

**장점**: 무료 시작, UV 데이터 포함, 실시간+예보 모두 제공
**단점**: 무료 일일 호출 한도 있음

### Option B: WeatherAPI.com

| 항목 | 내용 |
|-----|------|
| **무료 티어** | ❌ 없음 |
| **자외선 데이터** | ✅ `forecast.day.uv` 필드 |
| **요금** | Starter $15/월부터 |

### 결론: **OpenWeather One Call API 사용 권장**
- 무료 티어로 UV 데이터 포함
- 실시간 + 시간별/일별 예보 모두 제공
- 한국 주요 도시 커버리지 확인됨

## 3. 전세계 실시간 태풍 정보 (Typhoon API)

### Option A: OpenWeather One Call 4.0 **(단일 API로 해결 가능)**

| 항목 | 내용 |
|-----|------|
| **태풍 데이터** | ✅ `alerts` 필드 (storm/typhoon 경보 포함) |
| **무료 티어** | ✅ 있음 |
| **API 예시** | `https://api.openweathermap.org/data/2.5/onecall?lat=37.5665&lon=126.978&appid={key}` |

**장점**: 기존 OpenWeather 키 하나로 해결 가능
**단점**: 경보 기반이라 직접 태풍 경로 데이터는 아님

### Option B: 기상청 태풍 정보 (weather.go.kr)

| 항목 | 내용 |
|-----|------|
| **데이터 소스** | ✅ 기상청 공식 태풍 정보 |
| **API** | ⚠️ 기상자료개방포털(data.kma.go.kr)이 현재 공사중 |
| **웹 크롤링** | weather.go.kr/w/hazard/typhoon.do 에서 태풍 정보 제공 |
| **법적 문제** | ⚠️ 크롤링 시 법적 리스크 존재 |

**대안**: 기상청 태풍 정보는 weather.go.kr에서 시각적으로 제공 중이지만, 공식 API가 아직 공사 중

### 결론: **OpenWeather alerts + 기상청 태풍 정보 웹스크래핑(또는 수동 업데이트) 병행**
- 실시간 경보는 OpenWeather로 해결
- 태풍 상세 경로/위치 데이터는 기상청 공식 채널에서 수동 업데이트 또는 크롤링 (법적 검토 필요)

## 6. 최저가 주유소 찾기 (Fuel Price API)

### Option A: 오피넷(OpenSE) 주유비 정보 API

| 항목 | 내용 |
|-----|------|
| **오픈API 포털** | https://www.openapi.kr 에서 제공 |
| **무료 티어** | ⚠️ 포털 검색 결과 없음 (API 등록 필요) |
| **데이터** | 주유소명, 주소, 종별가격(레귤러/휘발유/경유/LPG), 주유소 전화번호 |
| **업데이트** | 일일 업데이트 |
| **인증** | openapi.kr 회원 가입 + API 키 발급 |

**장점**: 한국 공식 주유 가격 데이터
**단점**: 포털에서 검색되지 않음 (다른 키워드로 재검색 필요), 등록 절차 필요

### Option B: 한국석유관리원 주유가격 정보

| 항목 | 내용 |
|-----|------|
| **데이터 소스** | ✅ 한국 석유 관리공식 데이터 |
| **API** | ⚠️ 공식 API 제공 여부 불명 |
| **웹 제공** | 주유가격 정보 포털 운영 중 |

### Option C: 네이버/카카오 지도 API

| 항목 | 내용 |
|-----|------|
| **주유소 정보** | ✅ 주유소 위치/전화번호 제공 |
| **가격 데이터** | ❌ 실시간 주유 가격 미제공 |
| **가격 크롤링** | ⚠️ 법적 리스크 존재 |

### 결론: **오피넷 재검색 + 한국석유관리원 공식 데이터 확인 필요**
- 주유비 데이터는 한국 특화 데이터라 글로벌 API로 해결 불가
- openapi.kr에서 다른 키워드(`주유`, `석유`, `연료`)로 재검색 필요
- 데이터가 없다면 **수동 업데이트 또는 크롤링** 대안 고려 (법적 검토 필수)

## 7. 영양제 추천 서비스 (Static Data + Logic)

### API 불필요 — 정적 데이터 + 추천 로직으로 구현 가능

| 항목 | 내용 |
|-----|------|
| **데이터 소스** | 식품의약품안전처, NIH (National Institutes of Health), Mayo Clinic 등 공신력 있는 출처 |
| **추천 로직** | 체크리스트 기반 (연령, 성별, 증상/고민, 생활습관 → 매칭) |
| **구현 방식** | 프론트엔드에서 정적 데이터 + 로직 실행 (서버 불필요) |
| **애드센스 주의** | ⚠️ YMYL (Your Money Your Life) 카테고리 — 건강 콘텐츠이므로 면책 문구 필수 |

**장점**: API 비용 0원, 실시간 데이터 필요 없음, SEO 콘텐츠로 활용 가능
**단점**: YMYL 카테고리로서 애드센스 심사 시 더 신중한 검토 필요

### 권장 데이터 구조
```json
{
  "supplement": {
    "name": "비타민 D",
    "nameKo": "비타민 D",
    "nameEn": "Vitamin D",
    "nameJa": "ビタミンD",
    "benefits": ["bone health", "immune system", "mood"],
    "benefitsKo": ["뼈 건강", "면역 체계", "기분 개선"],
    "recommendedDosage": "600-800 IU/일",
    "targetGroup": ["elderly", "indoor workers", "low sun exposure"],
    "interactions": ["calcium", "magnesium"],
    "sideEffects": ["과다 복용 시 신장 결석 위험"],
    "faq": [...]
  }
}
```

### 결론: **정적 데이터 + 프론트엔드 로직으로 구현**
- API 키/비용 불필요
- 공신력 있는 출처에서 원본 데이터 수집 필요
- YMYL 주의: "의학적 진단이 아니며 참고용" 문구 필수
